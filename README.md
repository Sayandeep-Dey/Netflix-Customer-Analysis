# Netflix-Customer-Analysis

## 📌 Overview

This project focuses on analyzing Netflix customer data to understand customer behavior, identify important trends, and generate meaningful business insights.

The project follows a data analytics workflow using Python, Pandas, NumPy, SQL, and Power BI. The analysis helps explore customer information, subscription patterns, revenue-related metrics, and other important business factors.

## 🎯 Objectives

The main objectives of this project are to:

* Analyze Netflix customer data
* Understand customer behavior and subscription patterns
* Identify important trends and relationships
* Perform data cleaning and exploratory data analysis
* Use SQL for business-focused analysis
* Create an interactive Power BI dashboard
* Generate meaningful insights from customer data

## 🗂️ Dataset

The dataset contains Netflix customer-related information used to analyze customer behavior and business performance.

The analysis may include information such as:

* Customer details
* Subscription plans
* Customer age and demographics
* Subscription duration
* Payment information
* Revenue-related metrics
* Customer activity and preferences


## 🛠️ Tools & Technologies

* **Python** – Data analysis and processing
* **Pandas** – Data cleaning, manipulation, and analysis
* **NumPy** – Numerical operations
* **SQL** – Data querying and business analysis
* **Power BI** – Interactive dashboard creation
* **Jupyter Notebook** – Python-based analysis
